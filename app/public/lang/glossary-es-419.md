# Glossary: Spanish (Latin America), es-419

The term choices behind `es-419.json`. Keep each term the same everywhere; when
you add or change a string, use the word this list gives. If you change a term
here, change it in every string of the pack too.

## Voice

- Neutral Latin American Spanish, the tone of a casual app.
- Always **tú**, in its standard forms (tienes, puedes, elige, haz clic). Never
  usted, never vos (tenés, podés), never vosotros.
- Instructions in tooltips speak to the reader: "Elige una carpeta", "Suelta aquí
  un .zip". Button labels are infinitives: "Agregar", "Guardar", "Exportar".
- Results and toasts use "se" forms: "Se agregó {name}", "Se guardó {file}",
  "No se pudo leer: {error}".
- The band's tips keep their voices: WB writes whole, dry sentences; DJ AR is all
  lower case and loud; SHiZUKA is lower case, with "ne~", kaomoji and a little
  Japanese, kept exactly as written.

## Kept in English

MUGEN, Ikemen GO, Mugen Studio, the Studio ("el Studio"), E-Select, H-MUGEN,
WebMUGEN, energy.jp, KFM, Kung Fu Man, WB, DJ AR, SHiZUKA; file names and
extensions (.def .cns .air .sff .snd .fnt .act select.def system.def fight.def);
folder names (Content/, Dependencies, Settings, themes/, lifebars/,
Desktop Export / Website Export); engine setting keys and code words (GameWidth,
Config.Players, HitDef, ChangeAnim2, SelfAnimExist, TargetState, RemapPal,
p1sprpriority, portraitscale, localcoord, ownpal, [Files], [Constants]...);
SFF / AIR / CNS; the scene words screenpack, lifebars, sprite, netplay, roster,
mods, slot, hitboxes, helper, ranked, lobby, relay, rollback, netcode; the game's
own menu and mode names (PRESS N, NETWORK, PLAYER NAME, RANKED, CASUAL, HOST GAME,
JOIN GAME, VERSUS, Training, Options, Command List, Lock-On, Scene Viewer,
Single, Simul, Tag, Turns, Midnight Bliss); other programs' and web sites' own
button names (Cloudflare's "Create Token", Metered's "Add Credential", itch.io's
"Kind of project"); keyboard keys as printed (Ctrl, Shift, Enter, Esc, Tab,
Home, End, Backspace, caps lock); the move list's AIR glyph.

## Numbers

- "1x", "{n}x", MB, KB, GB as in English.
- No thousands separator in prose numbers ("1000 archivos"): neutral across Latin
  America.
- Ordinals: "1.er lugar", "2.º", "3.er".
